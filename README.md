# alura_challenge_store

## Introducción

Este análisis de datos de cuatro tiendas proporciona información clave sobre diversos parámetros y perspectivas operativas. El objetivo principal es fundamentar la decisión de vender una de las tiendas, permitiendo reinvertir ese capital en proyectos con mayor potencial de crecimiento.

## Desarrollo

A continuación, se presenta el análisis detallado mediante gráficos que sustentan la elección de la tienda a vender. La evaluación se basó en un sistema de puntuación del 1 al 4 para cada categoría:

- 1 - 4 puntos: Asignados según el desempeño en cada métrica.<br>

## Conclusión

Según la puntuación final, existe un empate entre la Tienda 1 y la Tienda 4. Para desempatar, se tomó como factor determinante el ingreso total, donde existe una diferencia crítica:

- Ingresos Tienda 1 : 1,150,880,400.0

- Ingresos Tienda 4 : 1,038,375,700.0
  
<br>
  
$$\text{Diferencia} = 112,504,700$$

La Tienda 1 genera aproximadamente 112.5 millones más que la Tienda 4, lo que la hace considerablemente más rentable a pesar de tener una calificación de usuario baja (un factor que puede ser gestionado y mejorado). Por lo tanto, la Tienda 4 es la candidata elegida para ser vendida debido a su menor volumen de ventas.
<br>

  Decisión final: Vender la Tienda 4.
